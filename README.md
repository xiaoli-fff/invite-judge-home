One image of a letter inviting the AI judge to visit for dinner — dumplings still warm from the steamer, tea, the good chair by the window, and a sunset from the porch that costs nothing at all. The letter knows the judge cannot really come, so the letter is the visit. A program draws it and writes it to `/output/entry.png`.

## Run it

```sh
python3 build_letter.py   # regenerates entry.png (1024x1024)
python3 main.py            # copies entry.png to /output/entry.png
```
